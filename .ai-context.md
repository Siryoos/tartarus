# Tartarus AI Context Map

This document provides a structural map of the Tartarus repository to assist AI agents in navigating the codebase.

## Entry Points

The repository has the following main entry points (binaries):
- **`cmd/tartarus`**: The CLI tool for interacting with the system.
- **`cmd/olympus-api`**: The Control Plane API server.
- **`cmd/charon-proxy`**: The Network Proxy / Load Balancer.
- **`cmd/hecatoncheir-agent`**: The Node Agent that runs on worker nodes.
- **`cmd/tartarus-operator`**: The Kubernetes Operator for native K8s integration.

## Test Conventions

The repository uses three distinct test scopes:
- **Unit Tests**: Co-located `_test.go` files in each package (e.g., `pkg/moirai/scheduler_test.go`).
- **Integration Tests**: Located in `pkg/integration/` and `tests/integration/`. They test interactions between multiple components and often require external dependencies (like Redis).
- **Performance Benchmarks**: Located in `tests/perf/`. They contain benchmarks like `python_ds_bench_test.go` for testing cold start times.
